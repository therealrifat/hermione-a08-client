# 🤝 BondHub - Connect, Care, and Transform Lives Today

**BondHub** is a web-based community platform designed to connect volunteers, organizers, and underprivileged communities. It enables users to create, manage, and participate in social welfare initiatives such as winter clothing drives, food distribution, blood donation campaigns, and tree plantation drives.

🚀 **Live Site:** [https://hermione-a08-client.vercel.app/](https://hermione-a08-client.vercel.app/)

---

## ✨ Key Features

* 📅 **Event Creation & Management:** Users can quickly create social welfare events specifying date, location, category, and details. Organizers can also edit or delete their created events.
* 🙋‍♂️ **One-Click Participation:** Users can browse upcoming events and join initiatives with a single click.
* 📌 **Personal Dashboard:** Dedicated sections to track "My Joined Events" and "Manage My Events".
* 🔐 **Secure Authentication:** Seamless and safe authentication using Email/Password and Google OAuth.
* 🌓 **Light & Dark Mode:** Built-in theme switcher for a personalized user experience.
* 🖼️ **Community Gallery:** Highlights moments from previous volunteer initiatives.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (React), Tailwind CSS
* **Authentication:** Better Auth / OAuth (Google)
